# 装好工具架后的动作修复

旧首页视频 `rack__full__none__101` 的末态满足物理悬挂验收，但装架后有大幅绕行，换抓后转向约 61 秒，画面中机械臂一度离开全景范围。只检查最终 `success=true` 没有覆盖这种动作质量问题；这段录像不再作为当前版本的主演示。

## 原因和改动

- 原先固定的顶抓朝向让装架、取扳手和最终挂放落在不同的肘部姿态，底座与腕部需要大角度旋转。现在两次扳手抓取采用衔接一致的对向抓姿，保持在工作台前方完成转向。
- 位置执行器的阻尼使关节持续滞后于移动目标，逐步等待误差收敛的保护逻辑因此频繁暂停。现在按原执行器参数加入速度前馈：`u = q_ref + (kv/kp) * dq_ref`。轨迹检查和误差统计使用 `q_ref`，执行器输入 `u` 单独保存；电机增益、限幅和碰撞保护不变。
- 支架释放后先直线撤离 85 mm，再转向；释放后的第一次自由转向也立即纳入支架的障碍间距检查，避免旋转夹爪扫到挂钩。
- 支架落座检查不通过时立即终止。新全景的视野略加宽，能看到抬起的腕部；用于位姿估计的 RGB-D 相机参数不变。

关节误差超过 0.010 rad 时仍暂停推进；双侧接触、所持物体碰撞和最终承重验收保持启用。速度前馈只在工具架任务的关节空间移动中启用。控制器仍使用官方 FoundationPose 和重建表面，不以物体真值生成抓取或纠偏目标。

## 结果的版本边界

修复控制提交为 `f2a26ba5d1f1096bd6936d1d44b689e47f64efa4`。开发种子 0 的完整视觉运行通过，另有明确标记的真值机械诊断用于调试；两者都不计入正式成功率。

修订后的正式评测使用新种子 200–209，每配置 10 次，共 40 次；完整方法与关闭腕部观测的消融均采用相同动作修复。主视频按预定规则选择无扰动完整方法中的最低成功种子，失败录像保留原试验轨迹。全部结果见 [修订后报告](results/rack-revision-v2/README.md) 和 [视频清单](videos/rack-revision-v2/README.md)。

实测完整方法为无扰动 **3/10**、有扰动 **2/10**，关闭腕部观测均 **0/10**。完整方法的 Wilson 95% 区间分别为 **10.8%–60.3%** 和 **5.7%–51.0%**，两项方法比较的 Holm 校正 p 值均为 **0.5**。当前数据不能证明架构优越性，也未解决所有布局的任务失败。

[首轮 240 次结果](results/evaluation-v1/README.md) 与旧视频原文件完整保留，不能把其中工具架的 7/10 当成当前控制版本的成功率，也不能把两轮不同种子的差异当成修复效果的配对检验。

本轮仍发现取扳手时没有通过碰撞检查的抓取路径，以及挂上后在规定等待时间内摆动未达稳定阈值的情况；它们保留为真实失败。这次修复改善了已定位的绕行和跟踪停顿，不能据此宣称随机任务成功率提高。下一步可以扩展基于重建几何的抓取候选选择，并单独验证释放后的稳定控制。

墙钟耗时是在 8 路 CPU 仿真、共享 GPU 推理以及部分并行轨迹渲染/独立复核的负载下测得，详细负载说明见 [hardware.json](results/rack-revision-v2/hardware.json)。这些耗时不能当作独占机器下的推理或控制性能。

## 如何复核动作

旧视频的 [独立检查](results/rack-revision-v2/previous-video-audit.json) 未发现松手后夹爪托住工具，最终状态额外静置 30 秒仍稳定。这说明旧片的问题主要是路径与跟踪过程；末态成功不能替代逐段看动作。

新主视频为 seed 202，[全景＋腕部](videos/rack-revision-v2/rack__full__none__202.mp4) 和 [独立腕部](videos/rack-revision-v2/rack__full__none__202__wrist.mp4) 保留约 114 秒全过程。其换抓后转向约 12 秒、底座行程约 29°；这些是本段录像的测量，不是两轮不同种子的配对改善估计。

两段演示的 [原始轨迹测量](results/rack-revision-v2/motion-comparison.json)：

| 动作 | 旧视频 seed 101 | 新视频 seed 202 |
|---|---|---|
| 记录的全程仿真时间 | 178.92 s | 114.09 s |
| 装架后转移：时长 / 底座角行程 | 14.40 s / 158.68° | 12.12 s / 12.37° |
| 换抓后转向：时长 / 底座角行程 | 61.04 s / 163.35° | 12.04 s / 28.79° |

时长不含静态推理和离线规划的墙钟等待，分段值按 25 Hz 保存状态测量。

[新主视频独立复核](results/rack-revision-v2/main-video-motion-audit.json)恢复原始状态检查接触，并额外延长 30 秒检查稳定性，均通过；挂钩支撑法向力约 0.980 N。延长段只作为独立诊断，不加入正式试验结果，不拼接进主视频。复核命令：

```bash
MUJOCO_GL=egl PYOPENGL_PLATFORM=egl .venv/bin/python scripts/audit_rack_motion.py \
  --trial artifacts/试验目录 --output artifacts/motion-audit.json
```

轨迹接触复核的采样率为 25 Hz，不能证明采样之间绝无接触；在线控制器在每个 500 Hz 物理步另有碰撞与夹持保护。单元检查新增了实际 MuJoCo 位置执行器的移动参考跟踪测试及输入范围检查，连同原有检查共 25 项通过，日志保存在 [validation/](results/rack-revision-v2/validation/)。
