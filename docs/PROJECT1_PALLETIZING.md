# Project 1：视觉码垛的选型、实现与证据

应用为 UR5e + Robotiq 2F-85 对四个已知 CAD 料块执行两列两层码垛。源码、运行方法、图像、视频和独立指标构成技术展示素材；最终 Slides、口头展示和小组分工说明仍由小组整理。

## Task 1：文献与技术选择

本应用需要物体六维位姿、明确的层位和释放后的支撑关系。以下按任务匹配度比较，不是跨方法的实测排名。

| 候选 | 原理与能力 | 对本应用的判断 |
|---|---|---|
| 颜色 mask + RGB-D 质心/主轴 | 几何方法可获得目标区域、位置和主要方向；均匀对称体的完整方向不能唯一恢复 | 颜色分割用于定位；不把只求质心当成完整物体位姿。此几何方案未作为独立全流程基线运行。 |
| FoundationPose Model-based | 使用 RGB-D 和已知物体模型估计/跟踪物体位姿，提供学习式候选评分与细化 | 选择此路线；本机已有官方环境，CAD 同时供感知、碰撞及打印使用，可直接评价物体到机器人坐标的精度。 |
| GraspNet 的抓取检测路线 | 从 RGB-D/点云任务中研究通用物体抓取，提供抓取标注、基线和评价体系 | 若以后研究未知物体的抓取候选，可进一步考虑；本次选择“物体位姿 + 已知 CAD 抓取配置”以衔接层位和姿态评价。未安装或实测该基线。 |

FoundationPose 的论文同时讨论 Model-based 和 Model-free；本项目采用有 CAD 的 Model-based，未使用 Model-free 重建。其评分器、细化器和权重来自官方实现，数据适配与机器人集成见 [FOUNDATIONPOSE_INTEGRATION.md](FOUNDATIONPOSE_INTEGRATION.md)。[FoundationPose，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Wen_FoundationPose_Unified_6D_Pose_Estimation_and_Tracking_of_Novel_Objects_CVPR_2024_paper.html)

GraspNet 提供面向一般物体抓取的数据、标注和基线；它是本次选型参考，不能把其论文结果写成本项目实测结果。[GraspNet 项目](https://graspnet.net/)、[GraspNet-1Billion，CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/papers/Fang_GraspNet-1Billion_A_Large-Scale_Benchmark_for_General_Object_Grasping_CVPR_2020_paper.pdf)

相机采用固定 eye-to-hand，使用棋盘角点估计内参、已知坐标对应估计外参，以减少相机运动带来的额外变量。OpenCV 文档给出针孔投影、内参和外参估计接口；固定相机和成像配置不变时可复用已估计参数。[OpenCV calib3d](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)

仿真沿用已验证的 MuJoCo/Menagerie 设备和接触动力学；轨迹沿用 Python/SciPy 的连续离线 IK 与密集采样碰撞检查，不新增 ROS 2/MoveIt 2 依赖。此选择减少当前环境和坐标接口改动，但不具备通用全局避障搜索，遇到本轨迹模板不可达或有碰撞时中止。

模型选择平顶、平底、单角切边的 80×50×40 mm 料块，使层间支撑充分，同时保留可见不对称结构。任务安排两列两层，层间重新观测支撑块；已有异形块和工具场景继续作为功能回归。

## Task 2–6：实现与核验入口

| 任务 | 方法与运行入口 | 已有证据和边界 |
|---|---|---|
| Task 2 内参标定 | `scripts/run_camera_calibration.py`；渲染棋盘图、检测角点、估计 K、留出图复验 | 历史独立标定：19 张有效训练图、4 张留出图，每图平均 RMSE 0.050 px。模拟器 K 仅用于评价。见 [calibration.json](results/calibration.json)。 |
| Task 3 相机—机器人标定 | 固定相机与已知 3D–2D 对应，估计 `world_T_camera` | 5 张训练、5 张独立验证，复验 RMSE 0.074 px，参考误差 4.25 mm / 0.122°。`world` 为安装参考坐标，需区别模型 base body 的轴向。 |
| Task 4 物体定位 | HSV mask；四种颜色各有一个实例 | 两种初始位置/方向布局，记录每次目标及支撑块的 mask IoU；真值分割只用于计算 IoU。当前不处理同色多实例或混杂堆料。 |
| Task 5 位姿估计 | 官方 FoundationPose Model-based；估计 K 和已知 CAD；相机位姿经估计外参转换 | 两组共 24 次注册，来源提交、候选数量、输入及完成状态可追溯；目标平移误差约 3.75–4.37 mm，方向约 0.34–0.54°。使用近似平放先验。 |
| Task 6 机器人操作 | `scripts/run_palletizing.py`；CAD 抓取关系、支撑块 XY 重观测、层位、带载朝向对齐、连续 IK/碰撞检查、真实接触释放 | 两组视觉整垛 2/2，单件操作 8/8；位置、方向、层位、支撑力、稳定性均有独立评价。模拟器状态用于反馈、安全检查和评价，不为正常视觉模式生成物体目标真值。 |

完整运行与自检命令见 [PALLETIZING.md](PALLETIZING.md)。标定与码垛使用同一个固定相机，复用仓库的估计参数；更改相机时必须重新执行标定，不能换成模拟器真值参数。

## 实验设计与解释

两个布局各执行一次真值控制对照和一次完整视觉码垛。布局 0 从零水平角开始；布局 1 改变源位置并使用 12°、-12°、8°、-8° 初始朝向，码垛目标均为 0°。真值控制对照只用于分离感知和物理策略问题，正常视觉试验始终使用估计物体位姿。

最终验收同时要求指定支撑体接触力、支撑多边形内的质心余量、层中心高度、朝向、速度、额外五秒漂移和放置后位移。另用独立负例证明“对齐但悬空”不会通过。全部结果见 [palletizing.json](results/palletizing.json)。

较小槽位误差不等于完整位姿链同样精确：夹持、释放和支撑平面约束会改变误差表现。上层 XY 使用估计支撑块位置，因此会承接部分标定偏差；本次上层相对名义槽位最大偏差约 5.37 mm，仍在料块支撑余量和预设验收范围内。

原单层放置与新码垛使用不同模型、目标和验收，不把两者成功率直接当成相同任务的算法优劣比较。样本只有两个确定性布局，不能外推为随机环境的可靠性统计。软接触穿透、控制跟踪偏差和质量/摩擦假设均需在报告中保留。
