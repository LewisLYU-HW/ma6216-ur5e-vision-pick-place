基于官方 FoundationPose Model-based、估计标定参数和 MuJoCo，实现 UR5e + Robotiq 2F-85 四料块、两列两层物理码垛。沿用同一仓库和已有环境，保留 v0.2.0、v0.3.0 及其 Pick-and-Place 入口。

## 本版功能

- 使用可打印的 80×50×40 mm 平顶、单角切边料块，四种颜色区分四个实例。
- 根据视觉位姿抓取、带载转动并对齐至统一朝向；放上层前重新观察下层，以估计 XY 对齐。
- 对手臂、载荷和已有码垛进行碰撞检查，执行期间监测意外接触与双指有载保持。
- 上层必须由指定下层真实支撑，同时检查层高、方向、质心支撑余量和五秒稳定性。
- 提供料块打印 STL、四种颜色的米制 CAD、源代码、录像和可追溯实测摘要。

## 已执行验证

两种源位置/朝向布局，各完成纯物理对照 4/4 和完整视觉码垛 4/4。视觉整垛共 2/2，单件共 8/8；最终名义槽位 XY 误差为 1.15–5.37 mm，五秒最大位置漂移约 0.16 mm。上层接触力约 0.981 N，底层约 1.962 N，符合每件 0.10 kg 的测试质量。

两组共 24 次官方 FoundationPose 注册，均记录已验证的上游提交。还验证了“位置对齐但悬空”的负例不能通过，并完成原单物体、三工件及多种类物品物理回归。有限确定性布局不代表随机混杂环境的通用成功率。

## 复现

```bash
git clone --branch v0.4.0 --depth 1 https://github.com/LewisLYU-HW/ma6216-ur5e-vision-pick-place.git ma6216-palletizing-v0.4.0
cd ma6216-palletizing-v0.4.0
conda activate foundationpose
python scripts/check_setup.py --vision
python -u scripts/run_palletizing.py --output "artifacts/pallet_$(date +%Y%m%d_%H%M%S)" --record --viewer
```

`--layout 1` 使用位置与角度扰动；去掉 `--viewer` 可无窗口运行。默认使用仓库中固定相机的估计内外参，修改相机后重新标定。`--ground-truth` 只用于跳过视觉的明确物理对照。

新机器按 `docs/SETUP.md` 配置 Menagerie、官方 FoundationPose、CUDA 依赖和权重。本仓库不打包这些外部依赖。课程六项任务的实现、文献比较和实验材料见 `docs/PROJECT1_PALLETIZING.md`，完整码垛原理与输出见 `docs/PALLETIZING.md`。

## 打印与范围

附件打印包与仓库 `assets/palletizing` 对应。`stack_block_print_mm.stl` 按毫米、100% 导入切片软件，打印四份；`*_model_m.obj` 为米制感知模型，保留模型原点。质量、摩擦和接触参数为仿真假设，打印后需实测。

当前依赖已知 CAD、受控颜色、近似平放先验和明确的层位；单次动作内使用固定视觉目标，未实现连续视觉伺服。模型存在软接触穿透，不将仿真指标当作真机精度。实物打印、真机驱动、任意堆料和同色多实例均需另行验证。最终小组展示仍需根据文档、录像和数据整理。
