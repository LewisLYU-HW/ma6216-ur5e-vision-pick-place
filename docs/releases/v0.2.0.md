三种独立工件在同一个 MuJoCo 场景中，由 FoundationPose Model-based 和估计标定参数引导 UR5e + Robotiq 2F-85 连续抓放。

- 绿色非对称双斜角、橙色斜肩棱柱、紫色渐缩切角块。
- 固定源码提交：`8c165f80cc4086d6cbee7cee1d81271bc88336ca`。
- 一次固定布局的视觉场景完成 3/3，最终槽位 XY 误差为 1.288、1.000、1.098 mm；双指有载搬运接触比例均为 1.0。
- 提供三件毫米制 STL、米制 OBJ 和尺寸/哈希清单。附件为打印交接包；完整源码请下载 GitHub 自动生成的 Source code，或使用 Git 克隆。

## 复现

```bash
git clone --branch v0.2.0 --depth 1 https://github.com/LewisLYU-HW/ma6216-ur5e-vision-pick-place.git ma6216-workpieces-v0.2.0
cd ma6216-workpieces-v0.2.0
conda activate foundationpose
python scripts/check_setup.py --vision
python -u scripts/run_multi_pick_place.py --output "artifacts/workpieces_$(date +%Y%m%d_%H%M%S)" --record --viewer
```

新机器先按本版 `docs/SETUP.md` 获取 Menagerie、FoundationPose 和权重。该版本没有 `--collection` 参数。纯物理对照增加 `--ground-truth`；其输出不作为视觉结果。

打印 STL 按毫米、100% 缩放导入，三个尺寸分别为 74×40×44、64×38×42、68×42×48 mm。感知继续使用米制 OBJ，不要混用单位或原点。测试质量不等于打印实物质量。

本版是固定布局的单层抓放仿真，尚未实现堆叠或真机控制接口。真机组需适配实际相机、TCP、坐标和控制协议。完整指标与局限见本版 `docs/MULTI_OBJECT.md`。版本标签保留，后续升级不覆盖它。
