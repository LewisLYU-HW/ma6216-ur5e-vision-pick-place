# v1.0.0：FoundationPose 视觉引导两层码垛

将已验证的视觉码垛成果正式发布为 v1.0.0。本次仅更新版本说明、复现入口和打印包名称，仿真源码、模型、标定数据及实验结果与 v0.4.0 一致；原版本继续保留。`main` 和 `feat/palletizing` 同步到本版，v0.2.0 三工件及 v0.3.0 多种类物品入口继续可用。

## 已完成与验证

- UR5e + Robotiq 2F-85 在 MuJoCo 中完成四料块、两列两层的物理码垛。
- 使用估计标定参数、RGB-D、颜色 mask 和已知 CAD 调用官方 FoundationPose Model-based，进行坐标转换、带载朝向对齐及采样碰撞检查。
- 放置上层前重新观测下层块的 XY，验收指定支撑接触、层高、方向、质心支撑余量与五秒稳定性。
- 两种确定性布局的完整视觉试验各 4/4，整垛共 2/2、单件操作共 8/8；最终名义槽位 XY 误差 1.15–5.37 mm，五秒最大位置漂移约 0.16 mm。
- 保留物理对照、悬空负例、原单物体/三工件/多种类物品物理回归及可追溯推理记录。有限布局结果不代表随机混杂环境的通用成功率。

## 复现

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/LewisLYU-HW/ma6216-ur5e-vision-pick-place.git ma6216-palletizing-v1.0.0
cd ma6216-palletizing-v1.0.0
conda activate foundationpose
python scripts/check_setup.py --vision
python -u scripts/run_palletizing.py --output "artifacts/pallet_$(date +%Y%m%d_%H%M%S)" --record --viewer
```

新机器先按 [SETUP.md](../SETUP.md) 安装 Menagerie、官方 FoundationPose、CUDA 依赖和预训练权重。`--layout 1` 使用第二组位置与角度；`--ground-truth` 跳过视觉，仅用于物理对照。修改相机后需重新标定。完整方法与结果见 [PALLETIZING.md](../PALLETIZING.md)。

## 3D 打印与课程对应

下载附件 `MA6216-v1.0.0-pallet-blocks-print.zip`，或使用仓库 `assets/palletizing/stack_block_print_mm.stl`。按毫米、100% 缩放打印四份 80×50×40 mm 料块；建议绿、橙、紫、红，以匹配当前颜色分割。附件另含米制感知 OBJ 和尺寸/哈希清单；STL 本身不带颜色。

[Project 1 对应说明](../PROJECT1_PALLETIZING.md) 提供 Task 1–6 的选型、实现和实验依据，最终展示仍需小组整理。当前有动作间视觉重观测，尚未完成并对照评价闭环视觉控制，不能据此申报该 bonus。实物打印及真机尚未验证；硬件组需实测相机标定、TCP、基座坐标、控制接口及物理参数。
