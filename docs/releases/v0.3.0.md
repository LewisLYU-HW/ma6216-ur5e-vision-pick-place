增加真实扫描工具、球体和中空六角螺母，保留 v0.2.0 的三工件类型场景；使用 UR5e + Robotiq 2F-85、MuJoCo、估计标定参数及 FoundationPose Model-based。

## 本版包含什么

- `--collection diverse`：紫色扫描锤子、红色球体、黄色带通孔六角螺母，在同一场景连续抓放。
- 一次固定布局视觉试验完成 3/3；最终槽位 XY 误差分别为 2.500、2.225、0.713 mm，双指有载搬运接触比例均为 1.0。
- 绿色十字螺丝刀已经载入四物件预览并导出打印文件，**尚未验证抓取，不在自动抓放场景中**。
- 扫描工具来自 Google Scanned Objects 的 MuJoCo 转换库；网格/纹理为 CC-BY-4.0，XML 为 MIT，来源与哈希保留在仓库中。两件扫描工具以原尺寸 50% 导入。
- 四件均提供经封闭性和尺寸检查的打印 STL，以及米制感知 OBJ。打印附件附带来源说明。

## 复现自动抓放

```bash
git clone --branch v0.3.0 --depth 1 https://github.com/LewisLYU-HW/ma6216-ur5e-vision-pick-place.git ma6216-diverse-v0.3.0
cd ma6216-diverse-v0.3.0
conda activate foundationpose
python scripts/check_setup.py --vision
python -u scripts/run_multi_pick_place.py --collection diverse --output "artifacts/diverse_$(date +%Y%m%d_%H%M%S)" --record --viewer
```

新机器先按本版 `docs/SETUP.md` 配置外部模型、环境和权重。公开克隆不会携带开发机的 Conda 环境。纯物理对照增加 `--ground-truth`，不加载 FoundationPose。

## 查看绿色十字螺丝刀

在上述目录运行：

```bash
python scripts/preview_object_library.py --output "artifacts/preview_$(date +%Y%m%d_%H%M%S)" --viewer
```

这个入口同时显示四件物品，机械臂保持待机，不执行抓取。最新版另可使用 `--collection workpieces` 运行旧三工件类型；严格复现旧阶段请使用 v0.2.0 标签。

## 范围与交接

当前使用受控颜色分割、已知 CAD 和指定夹持区，球体不报告唯一旋转角，螺母按 60° 对称性评价。最大非预期机器人穿透为 0.161 mm；工件与桌面/托盘最大软接触穿透约 2.64–4.17 mm，不能将结果表述为零穿透或真机精度。

打印文件位于 `assets/printable_library`；STL 为毫米，OBJ 为米，扫描工具按半尺寸打印。未验证实物打印、螺丝刀抓取、码垛或真机控制。完整方法、失败记录和数值见 `docs/OBJECT_LIBRARY.md`，阶段选择见 `docs/VERSIONS.md`。以后码垛使用新分支和新版本，不移动这两个固定标签。
