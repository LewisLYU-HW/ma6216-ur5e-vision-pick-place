# 完整四阶段任务视频

**[全景＋腕部](overview-wrist.mp4)** · **[独立腕部](wrist.mp4)**

两段视频来自同一次 `--task complete --seed 0` 视觉运行，时长均为 **3 分 14.36 秒**。四个物体始终在同一个物理场景中，阶段之间没有重置。按原始 25 Hz 状态回放，保留全部转运、松爪、换抓和末尾稳定等待。

| 视频时间 | 阶段 |
|---|---|
| 00:00.60 | 扫描锤子归位 |
| 00:26.50 | 运动螺丝刀抓取与倾斜插架 |
| 01:11.16 | 安装独立工具架，释放后重新定位 |
| 02:13.66 | 扳手松爪换抓、穿孔挂放 |

挂放后保留 10 秒稳定等待，最终锤子、螺丝刀、支架和扳手均通过承重与稳定性验收，独立延长静置 30 秒也通过。三色轴表示最新视觉估计以及夹持期间由 FK 传播的位姿；腕部图像参与实际估计。

全景＋腕部为 1920×720，独立腕部为 960×720；H.264 / yuv420p、25 fps、faststart。视频为仿真时间，静态推理与离线规划的墙钟等待不计入播放时长。
