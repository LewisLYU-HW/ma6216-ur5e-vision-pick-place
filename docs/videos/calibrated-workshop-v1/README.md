# 使用估计腕部标定的完整任务录像

两段视频均来自新标定接入回归中 **seed400、有对准脉冲、iterative** 的同一份连续轨迹。腕部相机内参与相机—夹爪变换来自棋盘图像估计，不使用理想相机安装参数生成控制目标。

- [完整全景＋腕部](overview-wrist.mp4)：1920×720，25 fps，197.28秒。
- [同次独立腕部](wrist.mp4)：960×720，25 fps，197.28秒。

流程：锤子归位 → 运动螺丝刀抓取与倾斜插架 → 独立支架安装与重定位 → 扳手实际松爪换抓与穿孔挂放。扰动例中有一次实际扳手对准修正；`VISION residual` 表示估计残差，不代表独立真值误差。

这是已完成任务的25 Hz原始状态回放，没有重新推理、重新执行或拼接多次成功片段。视频有4932帧，源轨迹有4933个采样快照；回放采样与录像帧数分别记录。原轨迹完成四物体验收，并通过额外30秒被动物理稳定性检查。
