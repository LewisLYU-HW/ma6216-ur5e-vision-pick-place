# Electronics assembly — one continuous application demo

[Watch the complete 35-second demo](electronics_assembly_demo.mp4).

An UR5e with a Robotiq 2F-85 assembles a small sensor module in one continuous
MuJoCo run: enclosure loading → battery installation → PCB placement → cover
assembly → finished-unit transfer and release on the output tray. The main
camera shows the workcell, one inset follows the active component, a second
inset shows the rigidly mounted wrist camera, and the five
stage indicators follow the recorded task phase. The original simulated run is
about 95 seconds, presented at approximately 2.7× speed without task cuts.

This is an **additional scripted application demo**, not a vision-method
experiment, success-rate estimate, or additional FoundationPose evaluation.
Targets use surveyed fixture coordinates and simulated held-object offsets.
All five pickups use physical opposed finger contacts; the robot moves through
joint actuators. No object is teleported or welded to the gripper. Once seated
and released, the battery, PCB and cover are connected to the enclosure by
MuJoCo weld constraints representing simplified fastening. Actual screws,
flexible PCB deformation, electrical functionality and snap-fit mechanics are
not simulated. The enclosure has low walls and raised gripping features to
provide access for the 2F-85 fingers.

## Reproduce

From the repository root with the existing MuJoCo environment and Menagerie assets:

```bash
MUJOCO_GL=egl .venv/bin/python scripts/run_electronics_demo.py \
  --output artifacts/electronics-assembly-demo-new --render --seconds 35
```

The script writes one MP4, a state trajectory, initial/final stills and a run
summary. It refuses to render an unsuccessful run as the completed demo.
The published [summary](summary.json), [replay trajectory](trajectory.npz),
[validation](validation.json), and [provenance](provenance.json) document this
single run. These checks are development checks, not method benchmarks.

All component and workcell geometry is generated by the demo script. UR5e and
Robotiq assets are from the project's existing MuJoCo Menagerie installation;
see the repository's third-party notices. Existing benchmark data and the
workshop presentation are separate from this demonstration.
