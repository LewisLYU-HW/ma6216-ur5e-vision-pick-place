# 中止的 240 次视觉反馈计划

原计划包含四类任务、三种反馈模式、两种环境、每配置十个种子，共 240 次。开始后组员提出“50 次够了吧”，因此停止继续派发，允许已经运行的试验正常收尾。共启动并完成 **16 次**；剩余 224 次没有运行。

这 16 次的原始摘要在 [trials/](trials/)，原 [协议](protocol.json)、[完整计划顺序](schedule.json)、[调度器日志](scheduler.log) 和 [中止记录](superseded.json) 均保留。调度器终止后，已运行的子进程仍正常完成，所以调度器日志中的完成数少于最终 16 份摘要。

它们不构成完成的配对矩阵，不计算或混入正式成功率。替代方案使用独立种子 400–407，运行 48 次四阶段完整任务；控制器没有因这些结果而改动。原始 RGB-D、轨迹和终态继续保存在本机 `artifacts/visual_feedback_v1/`，RGB-D 已逐文件验证后无损压缩。
