# 估计腕部标定接入：完整任务回归

将腕部理想内参／安装变换替换为棋盘图像和机器人 FK 估计结果后，使用同一个开发回归种子400，分别运行无扰动、有对准脉冲两次完整流程。两次均实际使用新估计参数，均通过锤子归位、运动螺丝刀插架、支架安装、扳手松爪换抓与穿孔挂放，以及最终四物体验收。

这是两次接入回归，**不用于估计随机任务成功率，不混入此前48次评测**。种子400此前已有成功轨迹，选择它是为了检查替换标定后的功能回归；不能据此宣称新标定提高成功率。
