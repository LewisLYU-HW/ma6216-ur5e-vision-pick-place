# 实测摘要

这些数据来自各阶段实际输出；试验日期、条件和范围以对应说明为准。历史 JSON 已作精简；新统一评测保留原始运行命令和本机路径，组员复现时应替换 Python 环境与输出目录。

## 六类任务：240 次配对评测

[完整报告与置信区间](evaluation-v1/README.md) · [逐试验 CSV](evaluation-v1/trials.csv) · [逐观测位姿 CSV](evaluation-v1/pose_observations.csv) · [失败及配对视频](../videos/evaluation-v1/README.md)

每配置 10 次、种子 100–109，含完整方法、模块消融和规定扰动。保留所有有效任务失败；一次未初始化的纹理缓存异常单独归档并补跑，详见报告。选中视频的原始状态、全部试验摘要与控制台日志随仓库保存；完整 RGB-D、50 Hz 测量及其余轨迹位于工作站 `artifacts/evaluation_v1/`。

## 历史阶段摘要

- `calibration.json` 记录棋盘格检出数量、固定参数的留出图误差和仅供评价的相机参考误差。
- `cube-baseline.json` 汇总六个初始场景、八帧观测与六次物理抓放。首次场景包含两个额外静止跟踪帧；旋转误差按立方体的 24 种旋转对称计算。
- `workpiece-front.json` 是两种绿色工件摆放的完整数值验收与路径指标，旋转误差使用原始三维角度。
- `route-comparison.json` 比较同一红方块、同一保存的估计位姿下的两种布局和路线。各自的仿真时长从各自待机状态开始计。
- `multi-object.json` 与 `diverse-object.json` 记录两个多物体抓放场景的视觉、接触及最终放置结果。
- `palletizing.json` 记录四料块两列两层的两组纯物理对照和两组视觉码垛；包含每件的直接支撑体、接触力、层高、名义槽位与相对支撑块 XY 误差、质心余量和五秒漂移。24 次 FoundationPose 注册的提交与完成记录也保留在摘要中。

每次视觉试验的推理结果和实际动作都有独立输出。仿真真值用于评价或明确标记的控制对照。新机器复现的结果按本轮日志判定。
