# 实测摘要

这些 JSON 从 2026-11-04 的实际输出提取，原始路径信息已去除。

- `calibration.json` 记录棋盘格检出数量、固定参数的留出图误差和仅供评价的相机参考误差。
- `cube-baseline.json` 汇总六个初始场景、八帧观测与六次物理抓放。首次场景包含两个额外静止跟踪帧；旋转误差按立方体的 24 种旋转对称计算。
- `workpiece-front.json` 是两种绿色工件摆放的完整数值验收与路径指标，旋转误差使用原始三维角度。
- `route-comparison.json` 比较同一红方块、同一保存的估计位姿下的两种布局和路线。各自的仿真时长从各自待机状态开始计。

每次视觉试验的推理结果和实际动作都有独立输出。仿真真值用于评价或明确标记的控制对照。新机器复现的结果按本轮日志判定。
