# 背景失配：开发故障诊断

开发评测曾把 seed-0 的空工位背景用于所有种子，而支撑结构随种子变化。这与生产流程不一致；主报告已经改正为逐种子配对的空背景。

这里保留目标缺失条件下的开发故障，说明背景差分对过期背景的依赖。它是事后排查记录，**不是正常流程的正式性能，也不混入50场景主统计**。两版相应输入深度哈希全部相同，仅背景配对方式不同。
