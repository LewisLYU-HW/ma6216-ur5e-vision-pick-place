# 从 RGB-D 重建的任务模型

这里的 `plug` 和 `blocker` 是调用官方 FoundationPose Neural Object Field
重建后导出的表面，作为本分支的感知及碰撞规划输入。每件使用 24 张合成的
RGB-D 参考图、图像 mask 和已标定扫描相机位姿；重建进程没有读取模拟物体的
CAD 文件或顶点。仿真器仍需要几何来生成图像和物理接触。

每个目录包含可直接使用的 OBJ、纹理、重建参数和 `model_free.json`，其中
记录官方源码提交、训练步数和模型文件 SHA-256。`reference_capture.json`
保留参考图集的文件哈希；原始 RGB-D 与训练中间文件不随仓库分发，可按
[重建命令](../../docs/MODEL_FREE_TASKS.md)重新生成。

`plug` 使用 1,500 步、1.5 mm 网格提取分辨率、固定扫描相机位姿；`blocker`
使用 1,000 步、1.5 mm 分辨率，并启用上游参考位姿优化。模型原点为扫描坐标系，
单位为米。边界来自重建结果，未按已知 CAD 尺寸修正；并非打印用 CAD。

这是一组已标定的合成参考图实验，不代表任意手机照片或无标定扫描已经验证。
无需重新训练 FoundationPose 的位姿网络；官方预训练权重仍需按上游许可另行下载。
